# observed_equivalent_depth_range

Python project based on the template from Pedro Angulo-Umana.
***

# Installation

From the project root, create and activate a Conda environment on each machine:

```sh
conda env create --name observed_equivalent_depth_range --file environment.yml
conda activate observed_equivalent_depth_range
```

Install this project's Python package in editable mode:

```sh
python -m pip install -e .
```

Add project-specific dependencies to `environment.yml` and update the environment with
`conda env update --name observed_equivalent_depth_range --file environment.yml`.
